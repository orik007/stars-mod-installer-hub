- Actual publisher merge validates all 22 replacements, omits empty groups, preserves real groups and is stable when repeated.
- Actual `InstallCommandBuilder` and `InstallPrepareService` verify every Auto package and every option at target versions `2.4.0.2` and `2.5.0.0`: 64 preparations and 106 prepared file checks, all matching archive SHA-256. Manual entries are excluded.
- The 23 radio options have non-empty matches and keep the expected common files. Autoloader prepares exactly one indicator and all three identical shared components; other exclusive choices prepare exactly one wotmod.
- QuickLog's unsupported split was checked with the actual normalizer: no supported general template puts loose wotmods in `mods/version` while placing its config in `mods/configs`.
- All package downloads were sequential, with at least ten seconds between completed downloads and the next request. Existing six packages were reused.

No files were applied to a game installation, no downloaded program was executed, and game functionality was not tested. External dependencies and in-game settings remain user responsibilities. Package evidence hashes are local review evidence; they are not recurring reclassification triggers.
